# GlowMuse Landing Page

**Track:** Web Development & Designing  
**Level:** Level 1  
**Task:** Landing Page

GlowMuse is a fictional skincare brand landing page designed using HTML5 and CSS3. It features a soft lavender-and-cream colour palette, responsive layouts, product cards, a brand story, and navigation links.

## Features
- Sticky navigation bar
- Hero section with call-to-action buttons
- Brand story and skincare benefits
- Three featured product cards
- Skincare ritual section
- Footer with contact and social links
- Responsive desktop and mobile layouts

## Technologies Used
- HTML5
- CSS3

## How to Run
Open `index.html` in any modern web browser.
